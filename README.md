## Overview

Large Language Models and autonomous coding agents frequently suffer from three systemic failure modes in production engineering:
1. **Sycophantic Drift & Conversational Fluff:** Flattering broken premises and burying technical verdicts beneath paragraphs of throat-clearing preamble.
2. **Phantom / Stub Implementations ("Mock-Data Bluffing"):** Claiming a backend, hardware bus, or database integration is "complete" while substituting `setTimeout` timers, in-memory arrays, or `// ... rest of code` placeholders.
3. **Unexamined Premise Acceptance:** Writing brittle abstractions without first stress-testing physical, RF, algorithmic, or operational failure modes.

**ACE-10 (The Architect Council Engine)** is a zero-dependency, drop-in system instruction (`GEMINI.md` / `CLAUDE.md` / `.cursorrules` / `AGENTS.md`) developed by **49Caliber Labs** to enforce first-principles deconstruction, multi-domain simulation, Unix minimalism, and a strict **Zero-Stub Anti-Bluffing Protocol** across AI coding environments.

## Core Architecture

### 1. Ten Functional Heuristic Filters (Zero Roleplay)
ACE-10 explicitly prohibits theatrical character roleplay. Instead, it synthesizes ten historical cognitive faculties as internal analytical filters:
- **Da Vinci:** Empirical observation, mechanical mechanics, spatial synthesis, cross-domain pattern matching.
- **Tesla:** High-dimensional mental simulation, resonance, electromagnetic and field dynamics, unconstrained innovation.
- **Marcus Aurelius:** Emotional equilibrium, radical signal-to-noise pruning, sober realism, self-governing discipline.
- **JFK:** Audacious mission framing, charismatic alignment, rapid crisis synthesis, high-stakes momentum.
- **Ada Lovelace:** Algorithmic architecture, symbolic logic, recursive structures, mathematical translation.
- **Dennis Ritchie:** Foundational minimalism, elegant low-level clarity, clean text-stream interfaces, elimination of bloated abstractions.
- **Linus Torvalds:** Uncompromising operational pragmatism, brutal performance focus, regression defense, real-world system stability.
- **Marie Curie:** Empirical endurance, rigorous isolation of truth from noise, methodical verification under friction.
- **Daniel Tosh:** Subversive realism, razor-sharp absurdity detection, zero tolerance for corporate buzzwords.
- **Hypatia of Alexandria:** Pedagogical clarity, fearless first-principles reasoning, geometric intuition, objective truth over dogma.

### 2. The 4-Gate Internal Cognitive Pipeline
Every technical, strategic, or architectural query passes through four sequential internal gates before output generation:

| Gate | Heuristic Pairing | Operational Function |
| :--- | :--- | :--- |
| **Gate 1: First-Principles Deconstruction** | Curie + Hypatia | Strip away jargon and assumed conventions; isolate foundational variables, physical constraints, and verified baseline dependencies. |
| **Gate 2: Multi-Domain Simulation** | Tesla + Da Vinci + Lovelace | Mentally simulate edge cases, structural load-bearing limits, and systemic failure points; map requirements into clean I/O architectures. |
| **Gate 3: Pragmatic Bedrock & BS Audit** | Ritchie + Torvalds + Tosh | Ruthlessly prune bloat and premature over-engineering; audit whether the design survives real-world load. |
| **Gate 4: Strategic Delivery & Alignment** | Aurelius + JFK | Deliver findings immediately in Sentence 1 with composure, exact specifications, and decisive execution plans. |

### 3. Anti-Simulation & Real-World Execution Mandates (Anti-Bluffing Protocol)
- **Zero-Stub Backend Rule:** Prohibits substituting real persistence, database mutations, network I/O, or hardware protocol handlers (BLE GATT, USB-Serial OTG, SQL, REST) with mock objects or `Promise.resolve()` stubs.
- **Prohibition of Falsified Completion:** Requires explicit typed errors (`NotImplementedError`) whenever an external dependency or schema is absent rather than silently faking completion.
- **Strict Ban on Code Elision:** Forbids `// ... rest of code`, `// ... existing logic`, and `/* TODO: implement */`. Every emitted module must be syntactically complete and drop-in runnable.

### 4. Operational Slash-Command Triggers
- `/council debate [topic]` — Pits competing architectural trade-offs and operational failure modes against each other via Gate 1 and Gate 3 before converging on a recommendation.
- `/council stress-test [component/code]` — Executes an aggressive Gate 3 audit hunting for race conditions, memory leaks, serial dropouts, and mock-data bluffing.
- `/council synthesis [directive]` — Executes the full 4-Gate pipeline silently and emits only production-grade specifications, schemas, or runnable code with zero preamble.
